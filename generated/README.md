# Сгенерированные документы

В этой папке будут размещены документы, автоматически сгенерированные системой сборки:

- `*.md` - консолидированные Markdown документы
- `*.html` - HTML версии документов
- `*.pdf` - PDF версии документов
- `*.docx` - DOCX версии документов

Рекомендуется не изменять файлы в этой папке вручную, так как они будут перезаписаны при следующей сборке.
